## Why two licences

GPL-3.0 is written for software and reads poorly when applied to prose — its
terms about source code, object code and linking have no sensible meaning for a
SysEx table. CC BY-SA gives the documentation the same share-alike protection in
a licence actually designed for written work. This split is a common arrangement
and is not a weakening of either licence.
